数学模型

y₁ = A cos(ωt − kx)
y₂ = A cos(ωt + kx)
y = y₁ + y₂
y = 2A cos(kx) cos(ωt)
其中 k = 2π/λ
最大振幅2A = 80
相邻波节距离λ/2 = 110
节—腹距离λ/4 = 55
当前整体因子cosωt = 1.00
此时 cosωt ≈ 1，驻波处于最大形变状态。波腹达到最大位移，波节仍保持不动。

观察要点

波节

振幅始终为 0 的位置。对本页面采用的余弦型驻波，波节满足 x = (2n+1)λ/4。

波腹

振幅最大的点，最大振幅为 2A。波腹满足 x = nλ/2。

相位关系

同一对相邻波节之间的质点同相振动；相邻两个波段的质点反相振动。

能量特点

理想驻波没有平均净能量向前传输，但各波段内动能与弹性势能不断相互转化。

操作建议：点击 “t = T/4”，你会看到所有质点同时经过平衡位置；再点击 “t = 0” 或 “t = T/2”，比较驻波形状上下翻转的特点。
